## 1. 環境の全体像
- OP-16環境は「近年で最もオープン」と評され、 **多数のリーダーが大会入賞できる健全なメタ**。 突出した1強なし。
- 上位4デッキで **ジャンケン (ダイヤモンド型) の相性関係**が成立 (英語圏・日本語圏で一致):
  - **ティーチ →(強)→ ナミ →(強)→ エネル →(強)→ ルフィ →(強)→ ティーチ (循環)**
- 環境トップ5 (紫エネル・青黄ナミ・青緑ルフィ・黒黄ティーチ・黄紫ロシナンテ等) で全体の約60%。

## 3. デッキ別詳細 (特徴・キーカード・勝ち筋・弱点)

### 紫エネル (Tier1・使用率No.1級)
- **タイプ**: ドン加速から大型を毎ターン押し付ける中速。 除去イベント採用で完成度が非常に高い。
- **キーカード**: エネル OP15-118 (6c、 場のドン6以下なら相手効果で離れず・P10000、 登場時に上5枚確認) / エネル OP15-060 (6c・ブロッカー化で攻守両立) / イベント 万雷・神の裁き・雷龍 / 神官(ホーリー・オーム・サトリ)で早期展開。
- **勝ち筋**: 最短で6エネル着地 → リーダー効果でドン4追加付与 → ホーリー/オームの打点を跳ね上げ実質複数回攻撃の圧力で主導権。
- **弱点**: ドン処理・イベント使用順を誤ると打点急落。 回復・長期戦デッキへの圧力不足。 6エネルにアクセスできない中盤が脆い。

### 青黄ナミ (Tier1・環境最高の耐久 / エネルメタの本命)
- **タイプ**: 青のテンポ制圧 (バウンス・下送り) + 黄のライフ操作で長期戦を制するコントロール。
- **リーダー効果**: 自ターン1回ライフが離れた時に手札7以下で1ドロー。 ドン1で手札1捨て、 相手アタック時にリーダーP+2000 (**7000ラインまで上げて6000アタックをいなす**のが核)。
- **キーカード**: ゼウス(OP11-106)、 Mr.3ギャルディーノ(OP16-056)、 ナミ(EB03-053)、 ボルサリーノ(EB04-058)、 ニコ・ロビン(EB03-055=フィニッシャー)、 ゲッコー・モリア(OP14-104=回復)。
- **勝ち筋**: ドロー誘発でリソースを回し続け、 回復とブロッカーでリーサルをずらして相手を息切れさせ、 ニコ・ロビンで詰める。
- **弱点**: **リーダー効果の無効化と大型キャラの除去に極端に弱い** (= 黒黄ティーチが天敵)。

### 青緑ルフィ (Tier1・OP16新リーダー・アグロ)
- **タイプ**: ライフ4/P5000リーダー。 リーダー効果でドンを多用しテンポよく展開する速攻。
- **キーカード**: モンキー・D・ルフィ(OP16-034)×4、 Mr.3(OP16-056)、 クロコダイル(OP16-045)、 バギー(OP16-048)、 イワンコフ(OP16-026)。
- **勝ち筋**: 序盤から横展開して攻撃回数を稼ぐ。 余った2ドンをイベントコストにして盤面コントロールも可能なプラン幅。
- **弱点**: **リーダーパンプ系に弱い** (アタッカーが6000帯なので相手リーダーを7000〜8000に上げられるとリソースを削れない = ナミが苦手)。

### 黒黄ティーチ (Tier2・耐久コントロール・ナミの天敵)
- **タイプ**: 攻撃先変更とライフ操作でロングゲームを制する耐久。 トリガー豊富。
- **リーダー効果**: **相手の攻撃を実質手札1枚で受け流す**トリッキーな能力。
- **キーカード**: 10ティーチ(フィニッシャー、 リーダー効果無効化+大型止め)、 カタリーナ・デボン、 ドクQ、 イベント「おれの時代だァ!!!」「ゼハハハハハハ!!!」。
- **勝ち筋**: アタックを受け流し試合を長引かせ、 終盤に大型連打。 ライフからの理不尽な展開(トリガー)で相手の計算を崩す。
- **弱点**: **連続アタックに弱い** (吸えるアタックは基本1回/ターン)。 速攻・多面展開相手だと手札が枯渇。

### その他上位
- **黄紫ロシナンテ** (Tier1.5〜2): ドン加速+黄の受け。 ロー&ロシナンテの再現性がOP16海軍追加で向上。 ブロッカー突破が苦手なデッキに強い。
- **青黄ハンコック (ゾンビ型・Tier1復帰)**: デッキトップ操作でモリア/クエーサーをライフに仕込み、 ゲーム中複数回のライフヒール。 ⑥ボルサリーノ/⑥クマ/⑨ハンコック。
- **緑ミホーク (Tier3・テクニカル)**: レスト固定の盤面ロック+高い対応力。 ペローナ(サーチ)、 エレクトリカルルナ。
- **赤青エース (Tier2・OP16新)**: P8000以上の白ひげ団に速攻付与。 エドワード・ニューゲート(リーダーにダブルアタック+2000付与)。

## 4. 相性表 (主要マッチ、 複数ソース整合)
核となるジャンケン: `ティーチ →強→ ナミ →強→ エネル →強→ ルフィ →強→ ティーチ (循環)`

| 対面 | 有利側 | 理由 |
|---|---|---|
| ナミ vs エネル | **ナミ有利** | 6000ラインをリーダー7000でいなす |
| ナミ vs 青緑ルフィ | **ナミ微有利** | リーダーパンプで速攻を受け流す |
| ナミ vs 黒ヤマト | **ナミ有利** | 回復+ブロッカーでリーサルをずらし息切れ狙い |
| **ナミ vs ティーチ** | **ティーチ有利** | 10ティーチでリーダー効果無効化+大型止め |
| ナミ vs ロシナンテ | 五分 | 両者耐久で決定打が出づらい |
| ナミ vs 赤シャンクス/赤青ルーシー | ナミ微不利〜不利 | 大型除去・安定除去で盤面が残らない |
| エネル vs ロシナンテ | **エネル有利** | 盤面差で優位 |
| エネル vs 青緑ルフィ | **エネル微有利** | 除去イベント+6エネル除去耐性 |
| エネル vs ティーチ | **ティーチ有利** | 10ティーチ連打で耐久、 長期戦に弱い |
| ルフィ vs ティーチ | **ルフィ有利** | 連続アタックがティーチの弱点を突く |
- **青黄ナミが「大正解」と言われる理由**: 環境トップ5のうち黒黄ティーチ以外の全対面に有利を主張できる。 ただしティーチが増えると立場が悪化する構造。

## 6. メタゲームの読み方
- **「使用率の高いデッキに強いデッキを使う」**が基本。 現環境は紫エネル・青黄ナミが最多 → これらに勝てる選択が有効。
- **ダイヤモンド型を意識**: 完全な最強は無く、 自分のデッキが「循環のどこで有利/不利か」を把握。
- **キーとなる攻防原理**: リーダーパンプ (ナミの7000化) が6000アグロ(エネル・ルフィ)の天敵 / 効果無効化+大型止め (10ティーチ) がリーダー効果依存(ナミ)の天敵 / 連続アタック(ルフィ) が「1回しか受け流せない」耐久(ティーチ)の天敵。
- **仮想対面シミュレーション**を繰り返して各対面のリーサル計算・ドン管理・カウンター温存の判断を鍛える。 大規模大会ほど当日分布のメタ読みが勝率を左右。
