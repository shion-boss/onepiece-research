# アーキタイプ・色・マッチアップ別 立ち回り

> アグロ/ミッド/コントロールの戦い方、 6色の特性、 三竦み、 先攻後攻、 マリガンの集約。

> [deckbuilding.md](./deckbuilding.md)。 立ち回りの土台は [README.md](./README.md) の統一原則。

## 0. 4リソースの認識 (立ち回りの土台)
- **ゲームの4リソース = 手札 / ライフ / ドン!! / 盤面(キャラ)**。 すべてを「資源」として捉えられるかがレベルを分ける。
- **ライフ = 第二の手札** (リーダー攻撃をライフ受け = 手札+1、 カウンター = 手札-1) → **基本はリーダー攻撃をビビらずライフで受ける**。
- すべての攻め・受けは **手札枚数の損得**で判断し、 最後にリーダーを殴り切る。

---

## 1. アグロ (ビートダウン)
- **相手が盤面を作るより早くライフを削り切る**。 自分の速度が上回れば相手は何もできず負ける。 赤・緑が得意色。
- **自分の得意レンジ (序盤〜中盤) で必ず決着**。 長引くと不利 =「得意レンジを抜ける前に決着」。
- **リソースを使い切る前に決める** (手札補充が少ないアグロの最大の弱点は終盤のリソース切れ)。 手札を攻撃(展開)に全振り。
- **序盤は「6000+6000」で殴るのが理想** (5000+7000より良い。 より多くのカウンター値を要求)。 **低い打点から先に振る**。
- **押し切れる盤面が来たら一気に全力** (相手のブロッカー不在・アクティブドン枯渇を突く)。
- 具体例: **赤ゾロ** (ドン1で全キャラ+1000、 低コスト横並べ、 キッド&キラー/ディアブルジャンブがフィニッシャー) / **赤エース** (白ひげ団に速攻付与、 序盤サーチ→終盤エドワード・ニューゲート)。
- **相手が嫌がること**: 毎ターンカウンターを強制的に吐かされ手札が枯渇していくこと。

---

## 2. ミッドレンジ
- **アグロ寄りにもコントロール寄りにも動ける柔軟性**が最大の武器。 相手にデッキ内容を読ませず対面ごとに攻守を切り替える。
- **「KOをしつつキャラを展開する」動きが最強** (相手キャラを処理しながら自分だけ盤面を残す = 二重のテンポ)。
- **カウンター値の損得計算**: 盤面に残ると毎ターンアドを生む高パワーキャラ (エースキャラ) を守るためにこそカウンターを使う。 守った枚数分を取り返せないなら守らない。
- **三すくみ**: ミッドレンジはアグロに弱く、 コントロールに強い。
- 具体例: **緑ボニー** (相手アタック時ドン1レストで相手をレスト、 ドン管理が肝) / **紫ルフィ** (ドン加速で高コスト早期展開、 ライフ管理が必要)。
- **相手が嫌がること**: キャラを毎ターン KO/レストされ盤面が育たず、 リソース交換で常に負けさせられること。

---

## 3. コントロール
- **序盤〜中盤は防御重視で耐え、 終盤に相手が息切れしたところをキャラ展開で捲る**。 長期戦ほど有利。 アグロに弱く、 ミッドレンジに強い。
- **ライフ4枚以上の間はアタックを受けてリソースを増やす** (ライフ受け=手札補充)。
- **カウンター値を貯める** (序盤に無駄なカウンターを切らず終盤の防御しきりに備える。 「将来大量カウンターが要ると読めるなら今ライフで受けてカウンターを残す」= 未来への投資)。
- **除去(KO)は高コスト帯/厄介なキャラに集中**。 コストダウン効果と組み合わせて処理範囲を広げる。 盤面リセット/一斉除去で相手の展開を無に帰す。
- **終盤は「5000+7000」に切り替える** (序盤の6000+6000から発想を変える。 相手により多くの「カード枚数」を要求)。 = **序盤=カウンター"値"要求 / 終盤=カウンター"枚数"要求のピボット**が上級者の分岐点。
- 具体例: **青ドフラミンゴ** (トップ操作で七武海レスト登場、 バウンス処理) / **黒ルッチ** (コストダウン→KO連打→モリアで一斉展開) / **黄カタクリ** (トリガーを仕込み、 低ライフを守り切りつつライフ=第二の手札+トリガー源として能動運用)。
- **相手が嫌がること**: 出したキャラを片っ端から除去され盤面が育たず、 リソースを枯らされて息切れさせられること。

## 4. マッチアップ相性と立ち回りの変え方
- **三すくみ**: アグロ→(有利)→ミッドレンジ→(有利)→コントロール→(有利)→アグロ、 で一周。
- **最重要原則**: どれだけ盤面が負けていても、 最後にリーダーを殴り切った方が勝ち。 **アグロがコントロール相手に終盤の盤面勝負を挑むのは無謀** — 得意レンジを抜ける前に決着を急ぐ。
- **アグロミラー**: カーブ通りに無駄なく展開しテンポで優位。 速攻(ラッシュ)キャラは温存し、 相手のリソースが切れた瞬間にリーサル。
- **アグロ vs コントロール**: (アグロ側) 盤面勝負に付き合わず相手が息切れする前にライフを詰め切る。 (コントロール側) ライフを詰めるより盤面処理と受けを優先、 大型で制圧してから捲る。
- **コントロールミラー**: 引きこもると時間切れ(両者敗北)になりやすい → リーダーのみで相手ライフ残り2まで殴っておき、 大型が並ぶまでキャラは縦置き、 相手が守らざるを得ない場面で一斉攻撃してリソースを削る。 「相手のプランを想定して動く」ことが勝率を分ける。
- **共通の攻めどころ**: リーダーへの継続攻撃は避ける (相手の手札とカウンター値が増える悪循環)。 代わりに **相手の場のキャラを攻撃**して盤面優位を作る。

## 5. 先攻/後攻での立ち回りの違い
| | 先攻 | 後攻 |
|---|---|---|
| 1ターン目ドロー | なし | あり (手札1枚多い) |
| 到達ドン | 奇数 (1,3,5,7,9) | 偶数 (2,4,6,8,10) = ドン加速相当 |
| 適性プラン | **ライフプラン (速攻)** | **手札プラン (枯らし)** |
| 理想手札 | 奇数コスト (1,3,5) | 偶数コスト (2,4) |
- **後攻のドン+1の使い方**: 後攻2T目に4ドン使えるのが強み → 4コストキャラ展開、 または「1ドン付けリーダーで攻撃(5000)してからキャラ展開」。 偶数コストにキーカードが集中するデッキ (黒緑ペローナ等) は **絶対に相手に後攻を渡さない**。
- **じゃんけんの選択**: 速攻・アグロ(奇数カーブ)=先攻 / 手札枯らし・偶数最速ムーブ=後攻。 黒モリア=先攻回避 (先攻2T目4ドン展開が強いので相手にやらせない)。 **迷ったら「自デッキの1〜3T目の理想ムーブから逆算」**してどちらでその理想が実現するかで決める。
- **実践指標**: 自手札 > 相手手札 → 手札プラン / 自手札 < 相手手札 → ライフプラン。 例外: レベッカ・ビビ (リーダーがアタックできない設計) は先後問わず手札プラン。
- **攻撃順の基本**: 攻撃してからキャラを出す (相手に次の行動を見せず、 ライフのトリガーでキャラが除去される心配を減らす)。 ドンは攻撃前に付ける (攻撃回数とパワーラインを相手にばらさない。 例外=赤のパワー参照除去ケア時は先割り)。

## 6. マリガン (引き直し) の基準
- **最優先軸 = メインアタッカー (キーカード) の有無**。 カウンター値が高くてもキーカードが無ければマリガン。 逆にカウンターが無くてもキーカードがあればキープ。
- **サーチのみのキープは避ける** (5枚引き直し優先)。 **漠然としたマリガン禁止** — 対面ごとに欲しい2枚を先に決める。 **迷ったらキープ**。
- 先攻=奇数コスト(1,3,5)で動きが継続できる手札 / 後攻=2〜4コスト(偶数)で展開できる盤面。

---

## 7. カウンター値の管理 (立ち回り視点)
- **カウンター1枚=手札-1**。 守るために何枚失うかを常に数え、 取り返せないなら守らない。
- **ライフで受けられる内は受けて手札を温存** (強い攻撃ほどライフ受けが効率的)。
- **ライフ別の目安**: ライフ5→3までは安いチップを気軽に / ライフ4なら残り2枚まで安い攻撃のみ守る / **ライフ1〜2は手札を割いてでも守る**。 ただし **「ライフ×相手盤面」の二軸**で判断。 **0ライフは厳禁**。
- **キャラ攻撃への守り**: パワー6000超は1枚で守れれば守る / 5000は追撃なければ守る / **4000以下は基本守らない**。
- **切るべき場面**: ①盤面で生き残るエースキャラの防衛 ②リーサル阻止で勝ちが見える時 ③終盤の大量カウンターに備えた序盤の投資。
- **ブラフ**: ドン割り振り・カウンターの見せ方で「2000がない」と誤認させたり、 あえて守らず相手の判断を誘導する。

## 8. 色別の特徴・戦い方・対策

### 赤 (RED) — 小型速攻・アグロ
- **特徴**: 速攻が最も豊富、 自パワー+/相手パワー-、 パワー参照KO。 入門向けで安定展開。
- **対策/嫌がること**: 効果KO (パワー参照でないKO) とコスト着目の除去に弱い。 リーダー高パワー化 (ルフィのリーダー6000化等) で低パワー攻撃が通らなくなるのを嫌う。 ディアブルジャンブ/ブロッカー無視のリーサルを常に警戒。

### 緑 (GREEN) — レスト操作・要塞コントロール
- **特徴**: 相手キャラ/ドン/リーダーをレスト、 自キャラ・ドンをアクティブ、 レストKO。 攻撃経路を限定する要塞型防御。
- **対策/嫌がること**: 効果除去 (バウンス/効果KO) でロック役を処理するのが最良。 ボニーはドン残し依存なのでドンを使い切らせる動きが刺さる。 9ゾロ/10ドフラ出現前ターンは無理にキャラをレストさせない。

### 青 (BLUE) — バウンス・ハンデス・デッキ操作コントロール
- **特徴**: バウンス (KO扱いでないため耐性キャラも除去可)、 ドロー、 ハンデス、 デッキトップ操作。 妨害で遅延して長期戦。 中〜上級者向け。
- **対策/嫌がること**: 速攻(アグロ)に弱い (立ち上がりが遅い)。 テンポよく再展開して手数で押すと妨害が追いつかない。 手札を抱えすぎず使い切ればハンデスを腐らせられる。

### 紫 (PURPLE) — ドン操作・ドン加速・大型展開
- **特徴**: ドンをデッキに戻して発動/アクティブ・レストで追加、 コスト参照KO。 ドン加速で早期大型展開。 ドン計算が勝敗を分ける。
- **対策/嫌がること**: **追加ターンを絶対に許さない** (ブロッカー無しで最後のライフを受けた後にニカを出されると一方的に負ける → ブロッカー/ライフを温存)。 大型着地前の速攻・ドン加速を崩す妨害。

### 黒 (BLACK) — コスト操作・効果KO・除去コントロール
- **特徴**: 相手コストを上下してコスト参照KO、 トラッシュ活用 (蘇生/踏み倒し)。 単色は弱く混色主流。
- **対策/嫌がること**: **KO耐性を最も嫌う** (除去が効果KO依存)。 登場時効果封じ (黒ティーチ) に弱い。 立ち上がりが遅い。

### 黄 (YELLOW) — ライフ操作・トリガー・逆転
- **特徴**: 両者ライフ操作/回復、 ライフ参照KO、 トリガー豊富 (他色の倍積める)。 ライフ減少がメリットになる独特のギミック。
- **対策/嫌がること**: 大型キャラそのものの除去 (特に9コスト以上は処理手段が乏しい)。 ハンデス (手札を抱える性質)。 ライフレースが通りにくいので盤面除去+リソース攻めで長期戦を挑む。

### 混色 (2色) の傾向
- **メリット**: 2色の特性を両取り (青黒サカズキ=バウンス+除去、 緑紫ドフラ=レスト封殺+ドン加速大型、 紫黒ルフィ=加速+蘇生)。 「片方の弱点をもう片方で補完」する設計が強い。
- **デメリット**: 多くの混色リーダーは **ライフ5→4スタート**。 判断が複雑で中〜上級者向け。
