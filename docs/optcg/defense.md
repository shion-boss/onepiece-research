# 防御の技術 (カウンター判断・ライフ受け・ブロッカー・要求値計算・トリガー)

> 守りの操作術の集約。 前提思想は [README.md](./README.md) の統一原則。 攻撃側の視点は
> [offense.md](./offense.md)。 配備 AI の守り側は既に整備済 (過剰防御 8e0d45d / 過剰カウンター
> 8b43070 / 対象不在イベント ebcd744,dfbdb19)。 本ドキュメントはその原則の根拠と精緻化。

---

## 0. 大原則: 守りの黄金律 =「手札を減らした分だけ取り戻せるなら良いカウンター」
- 守るたびに手札が1枚減り、 相手の残りカウンター1枚1枚の価値 (= 相手のリーサル達成力) が上がる。
- 減った手札ぶんの価値 (延命・盤面維持・相手リソース消費) を回収できないカウンターは悪手。
- **「守るのに何枚ハンドを失うか」を必ず計算してからカウンターを切る**。 「守れるなら何でもカウンター」は最頻出の初心者ミス。

---

## 1. カウンターを切る/切らない判断

### 切る判断 (基本原則)
- **「以降の攻撃を含め、 一番打点が低く、 かつ同値も受けない時だけ切る」**。
  - 理由: 序盤の低打点を先に守っておくと、 終盤の高打点に対処する時にカウンターを温存できる。
  - **悪い例**: 2T目の5000パンチを守り、 終盤7000パンチにもカウンターが必要になると、 5000を守った2000ぶんが「無駄打ち」になる。
- **同値を複数回受ける場合は「最初の同値で受けて」その後の選択肢を増やす**。
  - 例 (赤ゾロ先攻): 2T目5000はほぼ受ける。 3T目に「5000×3+6000」の最悪ケースを想定して逆算。
- **相手ドロー枚数も勘定に入れる** (「4T目までに5000が計3回」ならドロー加味で概ね全部守れる範囲、 等)。

### 切るべき「良いカウンター」= 価値回収できる3ケース
1. **エースキャラの防衛**: 場に残ると継続的にアドを生む高パワーユニット (シャンクス/ルフィ/キッド/ミホーク級) を守るのは手札投資に見合う。
2. **リーサル阻止**: 守れば勝ち = 手札損は無関係。 全ツッパで守る。
3. **将来への投資**: 序盤にあえてライフを減らして終盤の巨大カウンター連打シナリオを避ける (早めに受けて後で楽をする)。

### 切らない (受ける) 判断
- **リーダーへの攻撃は基本受ける／大事なキャラアタックを守る**。
- 手札が0になるほど守る／効果KOが防御に関係なく確定している／今の被弾より次ターン以降の札温存が重要な時は **受けるのが最適**。
- 弱いキャラアタック (5000以下) は基本スルーして札を温存。
  - 目安: パワー6000超は1枚で守れれば守る / 5000は追撃なければ守る / **4000以下は基本守らない**。

### 情報を漏らさない切り方 (上級)
- **カウンターの切り方から手札構成がバレる** (6000に「1000カウンター2枚」= 「2000カウンターを持っていない」と露出)。
- **手札が多い時はあえてライフで受けて、 相手に誤情報 (札があるかもしれない圧) を与える**のが最適解になり得る。

## 2. ライフで受ける判断 (ライフ = 手札に変わるリソース)
- **リーダーへの攻撃をライフで受ける = 手札が1枚増える**。 ライフは「後払いの手札」。
- **最も強い攻撃こそライフで受ける** (どんな巨大攻撃でも消費は「ライフ1点」)。 中打点を複数守るとカウンター値を大量消費。
- **手札2枚分のアド損の考え方**: カウンター2枚で1回守ると手札-2。 同じ攻撃をライフで受ければ手札±0 (むしろライフ→手札化で実質+1)。 **「2枚使って守る価値があるか」を常に天秤に**。
- **ライフ別の目安**:
  - ライフ5 → 3までは安いチップを気軽に受ける
  - ライフ4 → 残り2枚まで安い攻撃のみ守る
  - **ライフ1〜2 → 手札を割いてでも守る**
  - **0ライフは厳禁** (相手が全ドンを1体集中 → カウンター不能で負け。 ≥1ライフあれば相手はドンを分散せざるを得ず1つを凌げる)
- **「ライフ × 相手盤面」の二軸で判断**: 相手盤面が広い (横展開速攻) 時は守りの優先度が上がる。
- **能動的ライフ管理 (上級)**: 大量手札消費が予測される相手には、 **事前に自分からライフを削らせてカウンターを温存**する。 ライフを「守る対象」でなく「切るタイミングを選ぶ資源」として扱う。
- **マリガンの含意**: 「1000×5枚でも2000×5枚でも守れる回数は最大5回で同じ」→ 守れる回数は **カウンター値の絶対値でなく手札枚数**で決まる。 迷ったらキープ。

## 3. 要求値計算 (守備側視点)

### 基本式
- **要求値 = 付与ドン数 × 1000 + 1000**。 攻撃側から見た消費要求の目安: +1000上→1000カウンター1枚 / +2000以上→1〜2枚 / +3000以上→2枚確定 / +4000以上→最低3枚 (2000×2+1000×1)。

### ① 盾(未使用ライフ)・ブロッカーなし → 等価な全パンチで計算
- 「千の位が偶数の攻撃が偶数体いる」時に振り分けで要求効率が上がる (攻撃側の武器 = 守備側の警戒点)。
- 例 (4000キャラ2体+ドン): 15000一本→11000(6枚)要求 / 5000+5000+13000→1000+1000+9000(7枚)要求 (分割の方が枚数要求が増える)。

### ② ブロッカーがいる場合 → 「均等割り付けが板」
- ブロッカーは最小打点を止めに来るので、 **打点を均等に揃える**ことで「小さいのを止められて無駄」を避ける。
- **守備側の含意**: ブロッカーがいる時、 攻め手は打点を均等化してくる。 逆に打点がバラけていればブロッカーで最小打点を吸って有効防御になる。

### ③ 盾(複数枚)がある場合 → 階段状 / 振り幅 = 盾枚数×1000+1
- **盾1枚あたりのカウンター期待値は約800〜900** (最頻1000だがカウンター0のカードも混ざるため期待値は下がる)。 盾3枚で約2400。
- 攻め手はこの期待値を吸収するよう打点に「階段」を作る (盾2枚なら振り幅2001 → 例 7000-9000-9000-11000)。 → 守る側は「盾で偶然カウンターが出る前提」を過信しない。

### ④ 相手(=自分)の手札を考慮
- 相手手札3枚以下なら基本計算のまま。 手札が少なければ基礎計算から引き算するだけ。

### ⑤ リーサル計算の実例
- モリア9000+リーダー5000+10ドン=24000を2体割り=各12000。 3体なら27000÷3=9000。 中間(12000+9000)/2=10500 → 10000からが最適要求。

## 4. 攻撃パターンから逆算する守り (相手はこう攻めてくる)
- **序盤 (6000-6000型)**: 均等に振ると守備側は最低2000カウンターを吐かされる。 逆に相手が5000-7000と刻んでくれたら、 **7000をライフ受け+5000を1000カウンター**で合計1000だけで捌ける (守備側お得)。
- **終盤 (5000-7000型 = 枚数要求型)**: 盾/ライフが尽きた終盤は「合計カード枚数」を要求してくる。 5000-7000は3枚要求 (6000-6000の2枚より多い) → 守備側手札を枯らして最終リーサルを通しにくる。
- **階段攻撃 (5000リーダー始動)**: 相手はまず5000で小さく殴ってカウンターを吐かせ、 カウンター配置を観測してから大型を通す → 守備側は **最初の小攻撃で情報を出しすぎない**。
- **アタック順の鉄則 (攻撃側の常識=守備側の読み材料)**: 「最初に9000で攻撃したら以降それ以下では攻撃しない」= 必ず低→高で上げてくる → **先に来た打点より低い打点は後から来ない**と読んでカウンターを配分できる。

## 5. ブロッカーの使い方

### 基本
- ブロッカーは「どんな強い攻撃も1体で受け止められる」万能防御だが、 **明確な弱点3つ**:
  1. **強い攻撃がない対面では活躍しない** (5000連打相手だと割に合わない)。
  2. **アタッカー枠を奪う** (盤面の攻め手が減る)。
  3. **除去されるリスク** (相手の効果KO・バトルKOで消される)。
- **大型連打 (高打点1〜2発) には有効／5000連打には無効**。 1体で大打点を吸えるのが本質価値。

### 高パワー vs 低パワーの使い分け
- **強ブロッカー (5000+)**: 早期に置いて盤面維持。 返しがリーサルにならない時は **攻撃にも使う (兼用)**。
- **弱ブロッカー (5000以下)**: 終盤に置いて大型攻撃を1発吸わせる。 序盤に置かない。

### 兼用・タイミングの規律
- **「ブロッカーで攻撃してしまったから次のターン守れなかった」を避ける**。 ブロッカーで殴る前に「次ターン相手の攻撃を自分が受けきれるか」を必ず事前検討。
- **「安易にキャラをレストにしない」**: 相手の場がアクティブ多めの時、 無防備にレストすると守り (ブロック・後続アタック) の選択肢を失う。

## 6. 手札 = 選択肢 / カウンター枯渇の危険
- 手札は「守る札」であると同時に「選ぶ権利」。 使い切ると ①ここぞで守れない ②次ターンのプレイ選択肢が消える ③相手の残りカウンターの価値が上がる、 の三重苦。
- **「手札がなくなっては本末転倒」**: カウンター過剰使用は最大の禁忌。
- **デッキのカウンター枚数目安 (諸説)**: 多くのデッキで25〜35枚、 推奨30〜35、 最低25以上。 **2000カウンターを積極採用**すると守りやすく手札消費も抑えられる (詳細は [deckbuilding.md](./deckbuilding.md))。
- **覚えておくべき代表カウンターイベント** (読み合いに必須): ガードポイント、 過激な一撃(ラディカルビーム)、 レッドホーク、 パンクギブソン、 スリーサウザンドワールド、 地獄の審判 など各色に散在。 相手のこれらを警戒しつつ自分は温存。

## 7. リーダー効果・DON残しでの防御 (control の生命線)
- **相手ターンの防御に使えるリーダー/キャラ効果を意識**: −2000等のデバフは「アタック時効果っぽく見えて実は起動メイン」など発動タイミングに注意。 攻撃してきた相手の打点を下げて要求値を実質引き上げる/無効化する。
- **DON残しの規律**: カードは「マナカーブ通り」でなく「最適タイミング」で出す。 盤面を先に動かしてから新キャラを出し、 **DONを残して相手ターンの防御効果 (-power/リダイレクト/カウンター起動) に備える**。
  - リーダーの「相手アタック時」効果 (ドフラの redirect 等) は **相手ターンに active な DON を消費**する。 **自ターン終了時に active DON を必要数残さないと翌相手ターンに発動不能** ([[project_claude_teacher_data_collection]] の control 局で life 1 を 2 ターン守り勝った教訓)。
- **redirect (攻撃の対象変更)**: 大型アタックを別対象へ受け流す等でライフ・キャラを守る手段として計算に入れる。
- **低ライフ時の防御判断**: 「このターンあと**何回**殴られ得るか (相手の残 DON + rush)」を **先に数えてから** カウンター/ブロッカーを切れ (数え違いで守り札が空振りした実例)。

## 8. ダメージレース (殴り合い) と攻守の切り替え
- **「手札は殴ってから使え」**: 自分の攻撃を先に済ませてからキャラを出す/効果を使う。 ①相手にトリガーで盤面を作られるダメージを避け、 ②相手の選択肢を狭める。
- **攻撃側の要求式: 相手パワー + 2000X** (X = 吐かせたい手札枚数)。 守る時は逆にこの刻みを「受け or 最小カウンター」で捌く。
- **切り替えの判断軸**: 相手の残 DON・盤面・速度を見て、 「レースで勝てる (自分が先にリーサル)」なら攻め継続、 「間に合わない」なら守りに回る。
- **リーサル逆算**: 必要アタック回数・アタッカー数・平均打点・期待トリガーを全部数えてから攻撃順を確定。 相手リーダーパワー未満のキャラにはドンを乗せない (過剰打点の無駄)。

## 9. トリガーの活用 (守りの追加リソース)
- **トリガー = 相手のリーダーアタックでライフを引いた時、 コストなしで発動できる効果**。 守りの「ボーナス防御」。 発動は任意 (使わなければ非公開で手札に加わる)。
- **重要制約**:
  - 自分のターン中は発動不可 (相手の攻撃で引いた時だけ)。
  - **効果で手札に加えたライフからはトリガー発動不可** (「攻撃ダメージで引いた」ライフのみ)。
  - トリガーでキャラが出た場合、 そのキャラは次ターンからアタック可能。
  - イベントのトリガー発動は「イベント発動時」効果を誘発しない。
- **守りへの含意**: **ライフで受ける = トリガーを引く抽選を回す**。 ライフ受けは「手札化 + トリガー抽選」の二重の防御価値。 「ライフから出るカード (トリガー枠・レッドホーク等)」を積むと受けの期待値が上がり、 要求値計算でも「盾1枚≒800〜900カウンター相当」の期待値が積み上がる。

## 諸説の対立ポイント (両論併記)
- **カウンター値の質 vs 手札枚数**:
  - 値重視説 = 「2000カウンターを多く積むほど守りやすく手札消費を抑える」。
  - 枚数重視説 = 「1000×5でも2000×5でも守れる回数は5回で同じ。 枚数が本質」。
  - **調停**: 守れる"回数"は枚数律速、 守れる"打点の高さ"は値律速。 用途で使い分ける。
- **序盤の攻撃パターン**: 6000-6000 (値要求最大) vs 終盤5000-7000 (枚数要求最大)。 ゲームフェーズで最適が反転 (守備側もフェーズで受け方を変える)。
- **ライフをどこまで受けるか**: 「ライフ5なら3ダメまで受けて有利」は目安であり、 対面速度 (アグロ相手は早め) とデッキ次第で前後する。
