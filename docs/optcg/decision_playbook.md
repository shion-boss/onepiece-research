# 状況判断プレイブック (条件 → 判断 → 優先順位)

> 対戦中の各判断ポイントを「**条件 → 判断 → 理由/優先順位**」の即引き形式にまとめた決定木リファレンス。
> 原理の詳細は [offense.md](./offense.md) / [defense.md](./defense.md) / [advanced_mastery.md](./advanced_mastery.md)。
> **使い方**: 局面で迷ったら該当セクションの決定木を上から辿る。 唯一解が無い分岐は「原則 + トレードオフ」を明記。
> ⚠ 厳密な最適手は実際の盤面・両者残デッキ・手札・DON・トラッシュに依存 → recall でなく **計算 (要求値/NNA/リーサル逆算)** で詰める。

---

## 0. ターン開始時の総合判断 (毎ターン最初にやる)
```
① 自分の NNA を数える  = 相手手札 + 相手ライフ×2 + 1   (= あと何回5000攻撃を通せば勝ちか)
② 相手の NNA を数える  = 自分手札 + 自分ライフ×2 + 1
③ 相手のこのターンの最大攻撃回数を数える (相手アクティブキャラ + rush + リーダー)
   └→ それが自分ライフを超えるか?  超える → 「負けを防ぐ行動」を最優先で確定
④ レースか grind か決める:
   自分NNA < 相手NNA (自分が先に詰められる) → レース (攻めて削り切る)
   自分NNA > 相手NNA (相手が先に詰める)     → grind (盤面処理 + 受けでリソース勝ち)
   自手札 > 相手手札 → 手札プラン(横展開で削る) / 自手札 < 相手手札 → ライフプラン(速攻)
```
- **目先のアドより「ゲームに勝つ(NNAを1にする)」を優先**。 このターンのゴール(除去/展開/カウンター削り/リーサル)を1つ言語化してから動く。

## 1. マリガン (キープ or 全戻し)
```
メインアタッカー(キーカード)が手札にあるか?
├─ ある → キープ寄り
│    └─ 先攻: 奇数コスト(1,3,5)で継続できるか / 後攻: 2〜4コストで展開できるか → 満たせばキープ
├─ サーチのみ (メイン無し) → 全戻し (5枚引き直しの方が当たる)
└─ カウンターだけ高い (メイン無し) → 全戻し
```
- **迷ったらキープ** (迷う=欲しい札が1枚はある。 最悪は「出す札が無い」事故)。
- **カウンター値の有無は基準にしない**。 対面ごとに「見たい札2枚」を事前に決めておく。

---

## 2. 先攻 / 後攻の選択
```
自デッキの1〜3ターン目の理想ムーブは奇数コスト始動か偶数コスト始動か?
├─ 速攻・アグロ / 奇数カーブ (1,3,5始動) → 先攻 (ライフプラン)
├─ 手札枯らし / 偶数最速ムーブ (2,4,6始動) → 後攻 (手札プラン + 初手ドロー)
└─ 相手にやられると強いムーブ (黒モリアの先攻2T4ドン展開 等) → 相手に渡さない側を取る
```
- **迷ったら「理想ムーブがどちらで実現するか」で決める**。

---

## 3. 攻撃するか / しないか
```
攻撃はほぼ常に価値がある (相手にカウンター/ブロッカーを強制消費 = 手札を吐かせる)。
まず「迷ったらリーダーアタック」(ほぼノーリスクで相手手札-1 or ライフ-1)。
攻撃を控えるべき例外:
├─ この攻撃で自分のアタッカーがトリガー除去で失われるリスク > 得るもの
├─ 相手ライフを削ると相手の手札(カウンター)が増えNNAが上がる & 自分は詰めきれない
│    → リーダーでなく「相手キャラを攻撃」して盤面優位を作る
├─ 攻撃でキャラをレストにすると次の相手ターンに守れなくなる (ブロッカー/後続を失う)
└─ 全体除去(盤面リセット)が見えている → 過剰展開せず「除去されても仕事するキャラ」を残す
```
- 原則: **攻撃してこない相手は怖くない**。 圧をかけ続けないとリソース差はつかない ([[feedback_ai_too_passive_attack_pressure]])。

## 4. 攻撃先・攻撃順
```
【誰を殴るか】
リーダーより強いキャラを効果で取れない → まず5000でリーダーを殴りカウンターを1枚削ってからキャラ処理
相手の場に「立つだけでアドを生むキャラ」がいる → 除去 or キャラ攻撃で処理優先
それ以外 → リーダーを削る (NNAを下げる)

【キャラ先か リーダー先か】
原則: 攻撃可能なら『キャラ』から殴る (トリガー除去ケア = 先にリーダーで殴ると自アタッカーを失う)
例外: 相手が赤系でパワー参照除去トリガー → 自アタッカーにドンを振り除去圏外にしてから殴る
情報取り優先の局面 → まずリーダーで殴り相手の反応(受け/カウンター/ブロック)を見て残りの攻撃先を決める

【順番】
グラインド(通常) → 低パワー → 高パワー (階段。 各攻撃が前以上の要求値を積み相手カウンターを枯らす)
リーサル1発の分岐を押し付けたい → フロントロード(最初に最強打点。 相手にライフ受けを選ばせない)
```

## 5. DON!! 付与 (するか / 残すか / どこに)
```
付与に「具体的な理由」があるか?
├─ 除去回避 (相手トリガー/効果が4000以下除去) → 4000キャラに1ドンで5000にし逃がす。 他キャラで攻撃 ◎
├─ リーサル到達 / ブロッカー突破 / opp leader へ届かせる → 付ける ◎
├─ 高パワーキャラ(ウタ4c4000等)に付けて要求値を伸ばす → 付ける ◎ (低パワーへの付与は効率悪 → 温存)
└─ 理由なし (攻撃前に全キャラ均等先付け) → ✗ もったいない + 手の内バレ
残す価値 (付与+1000は相手ターン無効なので下記4用途のみ):
  ① カウンターイベントのコスト源  ② 起動/リアクション効果  ③ ブロッカー再起動  ④ 次ターンの展開
```
- **付与は攻撃宣言のギリギリまで見せない** (相手の守りを見てから通したい攻撃に回す = 情報優位)。
- **低パワーキャラを無理にレストで殴らせない** (DON浪費 + 次ターン相手にレスト先を与える二重の損)。
- リーダーへの付与が DON あたり drain 効率 最良 (フリーで殴れる leader を 8000 に > 小キャラに3ドンで5000)。

## 6. カウンター切るか / ライフで受けるか (最重要の防御判断)
```
そのリーダー攻撃は「以降の攻撃を含め 一番打点が低く、 かつ同値も受けない」か?
├─ No (もっと低い/同値がこの後来る) → 受ける (先に低打点を守ると後の高打点でカウンター枯渇)
└─ Yes → 切る候補。 ただし下記チェック:
     ・守るのに手札を何枚失う? 失う手札 ≦ 得るもの(延命/盤面/相手リソース消費) か?
     ・ライフで受ければ手札+1 (+トリガー抽選)。 「ライフ1を守るため手札2枚」は基本 損
     ・最強の攻撃こそライフで受ける (消費はライフ1点。 中打点を複数守ると値を大量消費)
必ず切る (手札損を無視) = ①リーサル阻止(守れば勝ち) ②盤面で生き残るエースの防衛 ③終盤大量カウンターへの序盤投資
```
```
【ライフ別の受け許容度】
ライフ5 → 3ダメまで安いチップは気軽に受ける
ライフ4 → 残り2枚まで、 安い攻撃のみ守る
ライフ1〜2 → 手札を割いてでも守る
0ライフ → 厳禁 (相手が全ドン1体集中でカウンター不能負け)
補正: 相手盤面が広い(横展開速攻)ほど守り優先度UP =「ライフ×相手盤面」の二軸で判断
```
- **キャラ攻撃への守り**: パワー6000超は1枚で守れれば守る / 5000は追撃なければ守る / **4000以下は基本守らない**。

## 7. ブロッカー 使うか / 温存か
```
相手の攻撃タイプは?
├─ 大型連打(高打点1〜2発) → ブロッカーが有効 (1体で大打点を吸える)
└─ 5000連打 → ブロッカー無効 (割に合わない。 カウンター/受けで捌く)
兼用ブロッカーで殴る前に必ず: 「次の相手ターン、 このブロッカー無しで受けきれるか?」を確認
  ├─ 受けきれる or 返しがリーサル → 攻撃に使ってよい (2つの仕事)
  └─ 受けきれない → 温存 (殴らず守りに残す)
純ブロッカー(低パワー) → 終盤に置いて大型を1発吸わせる。 序盤に置かない
```

## 8. リーサル判定 (確定リーサルか)
```
① 通す必要回数 = 相手ライフ枚数 + 顔到達回数 を数える
② 自分のアタック可能キャラ数を数える
③ ブロッカーがいれば平均パワーを計算 (吸われる分を引く)
④ 相手のアクティブドンを確認 (カウンターイベント/起動の余地)
⑤ 相手ライフからのトリガー(除去/カウンター)を想定
⑥ 自分の要求値合計 > 相手の総防御力(手札総カウンター値) → 確定リーサル
```
```
【ドン振り分け (詰め)】
1. 必ず通したい複数攻撃は まずパワーを均等化
2. ±2000以内で刻む (差が2000超だと弱いのを受け強いのを守る逃げ道を与える)
3. 平均値 = (2体プラン総火力÷2 と 3体プラン総火力÷3 の中間) → 500単位で切り下げてスタート
4. 「受けても守っても同要求値」の配分が最強 (例 10000-8000-8000 = 盾込10000要求)
5. 小型・パワー0キャラも計算に入れる。 相手リーダーより2000以上低いキャラはリーサル参加させ損
⚠ ライフ1の相手 (トリガーで捲るリスク) → 平均でなく「最初のアタックを強く」して確実に押し込む
```

## 9. 除去 (KO/バウンス) 撃つか / 温存か
```
対象は「リーダーより強い/立つとアドを生む」キャラか?
├─ Yes → 効率的に除去 (無駄トレードより効果KO/バウンスが効率的)。 除去できないなら早めにプラン切替
└─ No (弱いキャラ) → 温存 (低コストキャラでレスト中を撃つ等、 ドンを節約して処理)
リーサル前 → 攻撃前にブロッカーをレスト・キャラをKOしてから要求値を計算 (吸収を減らす)
相手が除去(KO/レスト)多用型 → あえてブロッカーを出さず、 ドローで手札を増やし除去を腐らせる
```

## 10. リーダー効果・起動効果をいつ使うか
```
エンジン型 (毎ターン低コストでアド/ドン加速: エネル等) → 毎ターン積極起動
脅威型 (強力だが1回: 大型登場・追加ターン等) → 最も効く盤面まで温存 (hold_for_threat)
相手ターン用 (リーダーの相手アタック時効果: ドフラ redirect / -power 等)
  → 自ターン終了時に「必要な active DON」を残しておく (残さないと翌相手ターンに発動不能)
低ライフ control → 攻撃/パンプでDONを全部レストにせず、 redirect/カウンター用の active DON を残す
```

## 11. 相手の手札・トリガーの読み (情報)
```
相手のカウンターの切り方から推測:
├─ 6000攻撃を「1000カウンター2枚」で守った → 2000カウンターを持っていない可能性が高い
├─ 6000-6000を両方受けた(切らなかった)   → 2000カウンターを持っていない (あれば1枚で守れる)
└─ トラッシュから逆算: 標準2000カウンター8〜10枚、 うち6枚落ち → 残り約4枚 → 手札に2枚以上ある確率は低い
相手のアクティブドンが無い → イベントカウンター/コスト付き効果は撃てないと読める
トリガー期待値: デッキにトリガー 2枚≈20% / 5枚≈40% / 8枚≈60% がライフに含まれる
  → 相手残ライフが多いほど詰めると強トリガーを踏むリスクUP (無理に削らない判断も)
【自分が読まれない工夫】
攻撃を先に・キャラ展開は後 / 登場時効果なしキャラは後出し / アタックは小さい方から /
ドンは宣言ギリギリまで見せない / 手札多い時はあえてライフ受けして「札があるかも」の圧を残す
```

## クイック早見 (一言サマリ)
| 判断 | 一言原則 |
|---|---|
| ターン開始 | NNAを両者数える → レースか grind か決める |
| マリガン | メインアタッカーの有無が全て。 迷ったらキープ |
| 攻撃するか | ほぼ常に価値あり。 迷ったらリーダーアタック |
| 攻撃順 | グラインド=低→高 / 一発リーサル=フロントロード。 キャラから殴る |
| DON付与 | 理由(除去回避/リーサル/突破)ある時だけ。 均等先付けは✗。 残して情報優位 |
| カウンター | 「以降含め最低打点かつ同値も受けない」時だけ切る。 最強はライフ受け |
| ライフ受け | ライフ=第二の手札。 ライフ1守る < 手札1〜2枚。 0ライフ厳禁 |
| ブロッカー | 大型連打に有効・5000連打に無効。 殴る前に次ターン受けきれるか確認 |
| リーサル | 均等化→±2000で刻む→受けても守っても同要求値。 ライフ1は最強打点から |
| 除去 | リーダー超えキャラに集中。 弱いキャラは温存 |
| リーダー効果 | エンジン型=毎ターン / 脅威型=温存 / 相手ターン用=active DON残す |
