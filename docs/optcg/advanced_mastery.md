## 0. メタ認識 — このゲームの正体
- **「このゲームは相手のライフを0にするゲームでも盤面を消すゲームでもなく、 自分のNNA(必要攻撃回数)を先に1にするゲーム」** (すけ氏)。 あらゆる行動を「勝利=最後の一撃を通す」に翻訳して考える。
- **決定的な非対称性**: 「パワー10000で殴っても5000で殴っても、 相手が受ければライフは1しか減らない」→ 1回の巨大攻撃より **複数回の波状攻撃**が効率的。 これがOPTCGで低コスト横展開が強い構造的理由。
- **「攻撃回数の多い方が、 相手のリソースを早く削り切って勝つ」**。 盤面(キャラ)は「殴る回数を増やす資産」として評価する (5000を2体 > 10000を1体、 がしばしば正しい)。

### NNA (必要攻撃回数) の基本公式
- **`手札枚数 + ライフ×2 + 1 = 相手を倒すのに必要な5000攻撃の最大回数`**
  - 例: 相手が手札3・ライフ2 → `3 + 2×2 + 1 = 8`。 5000攻撃を8回通せば勝ち。
  - ゲーム開始時のNNAは概ね最大15。 これを先に1にできれば勝ち。
- **簡略計算法 (実戦の即時判断)**: 3桁を落として概算 (相手6000×2+9000+リーダー5000+ドン10 → 各値を丸めて合計→3桁戻して必要カウンター約20000)。 「このターン守れるか」が一瞬で出る。

## 1. アドバンテージ / テンポ

### 1-1. アドバンテージの細分化 (用語の正確な定義)
| 種別 | 定義 | OPTCG固有の重み |
|---|---|---|
| **カードアドバンテージ** | カード枚数全体(盤面+手札+復帰)の損得 | 総リソース |
| **ハンドアドバンテージ** | 手札枚数の増減に限定 | 手札=カウンター燃料なので特に重い |
| **ボードアドバンテージ** | 盤面のキャラのみ (DON!!/ステージ含まない) | 殴る回数の資産 |
| **ライフアドバンテージ** | 残りライフの差。 同時に「受けると手札になる予備リソース」 | OPTCG独自 |
| **テンポ** | 少ないDON!!で大きな効果を得た状態 | DON!!効率で数値化可能 |
| **情報アドバンテージ** | 相手の非公開情報を覗く/読む優位 | 攻撃設計で能動的に取れる |

### 1-2. テンポ = DON!!効率 (カードアドとのトレードオフ)
- 例: お玉(1c)+ゴムゴムのJET銃(4c)で8cキッドをKO → `8−(1+4)=3` DON!!分の得。 **ただしカードアド(手札枚数)は失っている** → テンポ(DON!!効率)とカードアド(枚数)は別軸でトレードオフ。 「今どちらが欲しいか」を毎手意識するのが上達の分岐点。

### 1-3. ボードは「相手にカウンター判断を強いる形」で作る
- 5ドンターンの選択: 「5c7000を置いて5000アタック1回」vs「3c5000を置いてリーダー7000アタック1回」→ **継続してアドを生む強い面**を作る方が優位。 単純なライフ削りより場の構築を優先する局面が多い。

## 2. リソース管理 — 交換レート

### 2-1. 基準換算と交換比率
- **基準: パワー1000 = DON!!1枚分**。 DON!!効率計算の土台。
- **1:1 / 2:1交換**: 「自分の何枚で相手の何枚を対処したか」。 **自分1枚で相手2枚 (1:2以上)** を作れれば有利。 自分2枚で相手1枚 (2:1で損) を避ける。

### 2-2. ドン効率 (最重要テクニック)
- **`付与DON!!の数 × 1000 + 1000 = カウンター要求値`**。 パワー差1000につき要求+1000。
- **良い付け方/悪い付け方**:
  - ✗ ナミ(1c/2000)に2DONでP5000 (要求1000) より
  - ○ **ウタ(4c/4000)に2DONでP7000** (要求3000)。 同じ2DON投資でリターン大。
  - P2000〜3000の低パワーキャラは5000ラインに乗せるのに2〜3DON必要で効率が悪い → **温存対象**。
- **レストコストという隠れコスト**: ダダン(2c/3000)に2DON付けて殴らせるより、 ゾロに2DON付けて殴る方が良い (**ダダンをレストにせず温存でき、 次ターンの相手のレスト先を与えない**)。

### 2-3. 手札の価値と「カウンターの交換比率」
- 手札は **攻撃札(殴る回数)と防御札(カウンター)を兼ねる二重資源** → 手札枚数管理が最重要。
- **カウンターの鉄則**: 「手札を減らした分だけ取り戻せるなら良いカウンター」。 使った枚数 ≦ 得るアドか常に検算。
- **良い2:1交換の例**: 緑ホーキンスをカウンター2枚で守り、 次ターンにホーキンスが相手キャラ1体KO+再アタック → 得た=相手キャラ1+相手手札(カウンター)2、 失った=自分手札2 = **自分2枚で相手3枚相当**。 守るべきは「立つだけでアドを生むエース級」。
- **警告**: 「強いカードだからと3〜4枚も手札を捨てて守る割に大したアドがない」= 典型的負けパターン。 「気づかない程度に少しずつつけられたリソース差」が最終的に大きな負債になる。

### 2-4. ライフをリソースとして使う (OPTCG最大の逆説)
- **リーダーへの攻撃を受けると、 そのライフカードが手札に加わる** → 「ライフで受ける=手札+1」。
- **基本指針 (全記事一致)**: 「基本的にはライフで受ける」「ビビらずライフで受けるべき」。 序盤はカウンターを切らず受けて手札に選択肢を蓄える。
- **数値で理解**: 先攻2T目の5000リーダーアタック → ライフで受ければ手札+2枚 (受けたライフ)。 2〜3ターン受け続けると4T目に手札が約4枚多くなる。
- **定式化**: 「ライフ1を守るために手札(相手のライフ2を削るリソース)を減らすのは非効率」。 ライフ1守る < 手札1〜2枚の攻撃力。
- **能動的ライフ管理 (上級)**: 大量手札消費が予測される相手には事前に自分からライフを削らせてカウンターを温存。

### 2-5. ライフを攻める側のジレンマ (削りすぎの罠)
- **初心者のNG**: 「ライフに攻め続けてキャラを放置」→ 相手の手札(カウンター値)が増え、 防御力とNNAが上がって逆に負ける。
- **理想の削り方**: 「手札1枚削る+ライフ1枚削る」または「ライフ2枚を一気に削ってリーサル圏へ」。 勝ちビジョン(NNA=1)が見える形を作る。

### 交換損得まとめ (実戦判断表)
| 交換 | 得か損か | 根拠 |
|---|---|---|
| DON!!1枚 → パワー+1000 | 基準(1:1) | 高パワーキャラに付けるほどカウンター要求効率↑ |
| 少DON!! → 相手高コストキャラKO | テンポ得・カードアド損 | お玉+JET銃で8c=3DON得だが手札消費 |
| 手札1〜2枚 → 自分ライフ1枚を守る | **基本は損** | ライフで受ければ手札+1。 ライフ1 < 手札1〜2 |
| 手札 → 立つだけでアドを生むエース維持 | 得(相手3枚相当) | ホーキンス例 |
| ライフを能動的に受ける → 手札+1 | 得(序盤) | NNAに余裕がある序盤ほど |
| 低パワーキャラを無理にレストで殴らせる | 損 | DON浪費+次ターン相手にレスト先を与える |

## 3. 相手の手札・プランの読み方 (カウンター値予測)
- **上級者はアタックを「情報を取る装置」として設計する**。 同値2発 (6000-6000) を並べる殴り方は相手の応答が手札情報を吐かせる。
- **6000-6000で殴り相手が両方受けた(カウンターを切らなかった)なら「2000カウンターを持っていない」と推測** (あれば1枚で守れるのに切らないのは不自然)。
- **カウンターの割り方から逆算**: 「6000に1000カウンター2枚」→ 2000カウンターを持っていない可能性が高い。
- **同値=値を要求 / 階段=枚数を要求**: 序盤はカウンター値を吐かせて手札の質を削り、 終盤は枚数を吐かせて量を削る。
- **統計的なカウンター期待値**: 盾1枚から得られる期待値は約800〜900 (最頻1000だがカウンター0も混ざる)。 盾3枚で約2400。 トリガー以外でライフ1枚から得られるカウンターは最大2000。
- **デッキタイプから逆算**: 大会上位のカウンター採用は25〜40枚程度。 重いデッキ(紫カイドウ)=カウンター多め / 軽いデッキ(赤単ゾロ)=少なめ。 **トラッシュから残数を逆算** (「標準構築で2000カウンターが8〜10枚、 うち6枚がトラッシュ→残り約4枚」)。
- **アクティブドンからの読み**: イベントカウンター/コスト付きカウンターはドンを要求 → アクティブドンが無ければ撃てないと読める。 デフォルトリソースは先攻9枚・後攻10枚が起点。

## 4. 情報戦・ブラフ (手の内を隠す・択の押し付け)
- **ブラフの本質 = 「相手にとって1番強い攻撃がわからない状況を作る」** = 相手が最適な受け方を計算できない状況。
- **偽リーサル**: 7000で殴り「9000が来るかも」と思わせる → 相手は9000をライフ受けしたく7000をカウンターで守り、 **存在しない9000を恐れて余分に手札を切る**。
- **「登場時効果のないキャラを先に出さない」** (相手に情報を渡さない): 先に出すと「大きなアクションは終わった」と判断され安心してカウンター配分を決められる → まずリーダーアタックして「この後何をするか分からない」状態を作る。 **「自分から見た世界だけでなく相手から見える世界を考える」**。
- **ドン残存・ドン振り分けによる情報操作**: ドンを残して攻撃すると相手は後続展開を想像させられる。 あえて嘘のドン振り分けを見せる (「10ドン全振りに見えて実は分散」)。
- **アタックは「小さい方から」始める**: 8000から殴ると「簡単にブロックされたくない」意図が透ける。 5000から入れば相手の反応を見て残りプランを変えられる。
- **択の押し付け**: 両プランのちょうど中間パワーで殴り、 どちらのプランか読ませず要求値を吊り上げる。 6000ブロッカーに5000でアタック開始し「ブロックすべきかカウンターで受けるか」の二択を強制。

## 5. リーサル/詰めの精度
- **要求値 = ライフ/ブロッカーの吸収を最小化する配分** (ライフ吸収を最小化するのが詰めの核心)。
- **「平均値で殴らない」が最重要**: ライフで受ける側は最強攻撃を選んで受ければ「1ライフ」に変換できる。 だから6000×2は弱い。 **強い攻撃を1本作る(5000→7000)**と、 相手は「7000をライフ、 5000にカウンター」を強いられ余分に吐く。
- **均等配分が起点**: 自盤面「5000/5000/5000/9000」に13ドン → 「7000/7000/8000/9000」に均すと最初の9000が無駄にならず全体の要求値が最大化。
- **階段配分で「受けても守っても同要求値」を作る**: 振り幅=「盾枚数×1000+1」。 配分「10000-8000-8000」だと相手がカウンターを切っても盾で受けても盾込10000要求 (「1パン目にカウンターを切ると要求値が爆増する」構造)。
- **リーサルの導出法 (相手ライフ1時)**: ①2体プランの総火力÷2 ②3体プランの総火力÷3 ③両者の平均→500単位で切り下げ→そこから殴り始める。 例: (12000+9000)÷2=10500 → 10000スタート。
- **⚠ ライフ1では平均でなく「最初のアタックを強く」** (トリガーで捲られるリスクがある盤面は1発目に打点を寄せる)。
- **速攻キャラの実効打点 = パワー − コスト×1000** (速攻ゾロ 3c/5000 = 実質2000キャラ相当)。 **相手リーダーよりパワーが2000以上低いキャラはリーサルに参加させ損**。
- **リスク設計 (3段階)**: 「全力リーサル」「通常リーサル」「隙あらばリーサル」を状況で使い分け。 「無理してリーサルを狙う理由はない」— 不確実なら盤面を固めて確実にNNAを下げる方が良い場面も多い。

## 6. 初心者がやりがちなミスと脱初心者のコツ
| ミス | 改善 |
|---|---|
| **「ドンは無限」の錯覚** (手なりで大型を出す) | 到達ドンMAXは決まっている (先攻=奇数、 後攻=偶数)。 使いたいタイミングから逆算。 マナカーブ通り≠良いプレイ |
| **ライフを守りすぎ** (何でもカウンター) | ライフで受ければ手札+2枚。 序盤はビビらず受ける |
| **ブロッカー・トリガーのケア漏れ** | 大型を出す前にリーダーアタック→トリガー被害を最小化。 相手の色から踏みうるトリガーを想定 |
| **登場時効果のないキャラを先出し** | 相手に「アクション終了」を悟らせる。 リーダーアタック優先で不確実性を残す |
| **置物キャラ(ロビン/お菊)を即レスト** | アクティブのまま盤面圧に。 ブロッカーで守れる時のみ攻撃 |

### 物理的ミス防止テク (勝率90.2% あーる。氏)
- **ドンを最初に小分けにして置く** (計算ミスを防ぐ。 「手の内がバレてもドン計算ミスよりマシ」)。
- **迷ったらリーダーアタック** (ほぼノーリスクで相手のブロッカーか手札を1枚削れる。 判断に詰まった時のデフォルト)。
- **対戦相手に聞く** (試合後に具体的な場面を挙げて意見を求める。 ボヤけた質問はNG)。

## 7. プレイングの言語化
- **「このターンのゴールは何か」を毎ターン言語化** (除去か、 盤面展開か、 カウンター削りか、 リーサルか)。 勝利条件(最後の一撃を通す)から逸れていないか問い直す。
- **「相手から見える世界」で考える** (行動順・ドン配分で狙いを悟らせない)。
- **採用理由・プレイ根拠を説明できる状態を目指す**。 学習は「上位プレイヤーの構築を1枚も変えず丸パクリ→なぜその枚数かを後から言語化」の順。 断定でなく「〜だと思う、 どう思う?」の対話姿勢。

## 8. 練習法・振り返り・大会思考
- **一人回し**: 「自分のデッキの動かし方」と「各局面の優先順位」を体に入れる。 仮想敵に大会優勝デッキを置くと実戦的。
- **計算の基礎作り**: 「白ひげミラーを大量にやって計算の基礎ができた」。 パワー・ドン・カウンターの数値感覚は反復でしか身につかない。
- **上手い人の長考 vs 初心者の長考**: 上手い人は練習済みの複数パターンから「次に何が起こるか」を予想。 初心者はゼロから新アイデアを生もうとする→大会中はやるべきでない (時間切れ+精度低)。
- **振り返りは「運で片付けない」定量的復習**: 全ターンを数字で検証。 カウンター不足で負けた→「どこで無駄にカウンターを使ったか」を全ターン検証。 想定外カードで負けた→運でなく「知識・経験不足」として記録。
- **試合開始時チェックリスト**: ①自ターン開始時に「相手のアタック回数」と「自分のライフ」を比較 ②アタック回数がライフを超えるなら負けを防ぐ行動を確定 ③目先のアドより「ゲームに勝つ」を優先。
- **上達目的のデッキ選択**: 紫ルフィ/緑紫ルフィ/青ドフラミンゴ等の **ドンアタック主体**は計算力が鍛えられる。 黄(トリガー依存)・黒(除去偏重)は計算に甘えが出やすい。 マイナーリーダーは解説が少なく比較できないので避ける。

## 統合: 上達に直結する思考フレーム
1. **すべてを攻撃回数(NNA)に翻訳** — `手札+ライフ×2+1`。 自分のNNAを先に1にする。
2. **軸を分けて評価** — テンポ(DON!!効率)とカードアド(枚数)は別軸でトレードオフ。 今どちらが欲しいかを毎手意識。
3. **DON!!は高パワーキャラに付けて要求値最大化** — 低パワーへの過剰付与・無駄レストを避ける。
4. **ライフはリソース** — 守る対象でなく序盤は受けて手札を増やす。 攻める側は削りすぎ(相手手札増)に注意。
5. **カウンターは交換比率で判断** — 失う手札 ≦ 得るアドか。 ライフ1のために手札2枚は基本切らない。
6. **平均値で殴らない/情報を渡さない** — 強い攻撃を1本作り、 登場時効果なしキャラは後出し、 アタックは小さい方から、 ドン残しで不確実性を作る。
7. **リーサルはライフ吸収を最小化する配分** — 均等割り+階段幅「盾枚数×1000+1」+「受けても守っても同要求値」。 ライフ1では最強打点から。
