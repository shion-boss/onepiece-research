# デッキ構築論 (50枚配分・カーブ・カウンター総量・採用枚数・比率・メタ枠)

> デッキの作り方の集約。 数値目安をテーマ別に列挙、 諸説対立は両論併記。 このプロジェクトの
> `engine/deckbuilder.py` / `engine/deck_generator.py` / `/decks/[slug]/analyze` の評価軸の裏付け。
> **信頼度**: ★★★=複数独立ソース一致+数学検証済 / ★★=複数ブログ一致 / ★=単一ソース or 逆算。

---

## 0. 前提 (ルール上の枠) ★★★
- メインデッキは **ちょうど50枚**。 リーダー1 + ドン!!カード10 は別枠。 同一カードナンバーは **最大4枚**。
- メインは **キャラ/イベント/ステージ**の3種。 全カードはリーダーと同じ色 (混色なら2色) のみ。
- ドンは毎ターン+2 (先攻1T目のみ+1)、 最大10。 使えるドンは概ね **先攻 1→3→5→7→9→10 / 後攻 2→4→6→8→10**。 このペースにコストを合わせるのがカーブ設計の核。
- **1試合で実際に触るカードは20〜25枚程度** (デッキ半分は使われず終わる) → 「圧縮 = 引きたい札の厚み・サーチ」で実効的にデッキを薄める発想。

---

## 1. リーダー・色・特徴
- **見るべき優先度 = リーダー効果 > 色 > その他 (パワー・ライフ枚数)**。 ★★
- **強いリーダー効果の2型**: (a) **汎用型** = 幅広く応用でき「ほぼ確実に強い」(ゾロ/旧サカズキ/ルッチ)、 (b) **爆発力型** = 条件が揃えば莫大なアド (黒黄ルフィ)。 **毎ターン使える・ノーコスト/低コスト**が高評価。 召喚酔いゲームゆえ **登場時効果が非常に重要**。
- **ライフ枚数**: 標準は **単色 = 5、 混色(2色) = 4**。 混色はカードプールが広い代わりにライフ-1 = 中級者以上向け。 ★★★
- **単色 vs 2色**: 推奨ルート = 「最初は単色で基礎を固め、 慣れたら混色」。
- **特徴シナジー**: リーダー効果が「トップ5枚から特定特徴をサーチ」型なら、 キャラを **特徴で統一**するとサーチ命中率・再現性UP。 **50枚制約ゆえコンセプトを絞れ** (「50枚で自分のやりたいことを最も高い確率で再現する」)。

---

## 2. コストカーブ設計
- **理想形 = 「綺麗な山型の弧」** (コストが上がるほど枚数を減らす)。 **最頻ゾーンは2〜3コスト**。 ★★
- 高コスト偏重の弊害: 序盤に高コストが手札に余りテンポロス → 動けず負ける (典型事故「手札に高コストだけ」)。
- **⚠ カーブ形は諸説/アーキ依存**: 教科書的な2〜3コスト山型 vs 実デッキの双峰型。 実際の大会級レシピ (赤紫ルフィ) のカーブ実測: 1c=8 / 2c=3 / 3c=8 / 4c=8 / 5c=4 / 6c=4 / 7c=7 / 9c=8 → **厳密な山型でなく1c・9cが厚い双峰型**。 = **勝ち筋に合わせてカーブは歪む** (純山型は理想論)。
- **序盤の担保**: 序盤札 (低コスト・サーチ) を4〜8枚厚く積み、 2T目に3〜4コストの展開札を出せる前提で構成。 余ったドンはキャラ付与(+1000/1ドン)に回し **ドンを遊ばせない**。

---

## 3. カウンター値の総量設計 (最も裏取りの強い領域)
- **カウンター値持ちカード = 25〜35枚 (推奨30〜35、 最低25以上)**。 大会上位は25〜40程度。 ★★★
- **デッキ全体のカウンター値合計 = 40000以上が標準目標**。 推奨テンプレ **+2000×12 + +1000×16 = 28枚 / 合計40000** (onehappy / cardgame-onepiece / 5656jetmazooka / toreca-hack で独立一致)。 ★★★
- 厚くする実例: 黒クロコダイルは **1000×22 + 2000×12 = 34枚 / 総46000**。
- **⚠ 1000 vs 2000 の配分 (最大の論点)**:
  - **説A (値重視・主流)**: +2000優先 (1枚で守れる量が大きく手札消費を抑える)。
  - **説B (枚数=回数重視・競技勢)**: 「1000×5でも2000×5でも守れる回数は5回で同じ」→ 値より **枚数**が防御回数を規定。
  - **調停**: 相手が2000刻みで要求する場面は+2000が効率的 (説A)、 1000単位で細かく散らされると枚数がボトルネック (説B)。 **実戦は +2000をコア防御札に据えつつ +1000で枚数を確保**。
- **⚠ 「専業カウンター枚数」の別カウント法 (定義違いの第2論点)**:
  - 説1 (全体カウント): カウンター値付きカード全体 (アタッカー兼用含む) で30〜35枚。
  - 説2 (専業カウント・競技統計): 「場に出さずカウンター専業に回すカード」は **14〜20枚** (理論20、 実運用14)。 根拠 =「1試合で実際に使うカウンターは上振れでも5枚程度」。
  - → 矛盾ではなく数え方の違い。 両者「合計40000前後」で一致。
- **カウンターイベント**: 総イベント10枚前後に内包、 単体は0〜4枚。 メインイベントはカウンター値を持たないので入れすぎると総カウンター低下 + 場にキャラが並ばない。 キャラカウンターは+2000が上限 → 3000以上の防御が要るならカウンターイベントが必要。
- **カウンターレス (値0) の許容**: 明確な上限なし。 逆算で「値持ち30枚+/合計40000+」を満たす残り (≒10〜20枚) がカウンターレス枠。 カウンターレスは **メインアタッカーであることが多くむしろキープ対象**。
- **アーキ別**: 重い (コントロール) ほどカウンター多め、 軽い (アグロ) ほど少なめ。

## 4. ドン加速・ランプ / キーカードの採用枚数
- **ドン加速 (ランプ、 主に紫)**: 通常の毎ターン+2に加えドンデッキから追加供給。 **最速先攻2T目から加速できる起点カードは4投必須**。 単一4枚では安定せず、 **同役割2種8枚で初手成功率85%前後** (実例: 紫カイドウで鬼ヶ島+ジャック/うるティ計8枚→86.75%)。 デッキの約1/3 (17〜19枚) をドン加速に割く構築も実在。
- **キーカードの採用枚数 (確率論)** ★★★ (hypergeometric で検証済):
  - **初手5枚で1枚以上引ける確率**: 1枚=10.0% / 2枚=19.2% / 3枚=27.6% / **4枚=35.3%** / 5枚=42.3% / **8枚(2種)=59.9%**。 マリガン込み: 4枚=58.1% / 8枚=83.9%。
  - 覚え方: **8枚で1ゲーム2〜3枚、 12枚で3〜4枚**来る。
  - **4枚 (最大投入) の基準**: ①毎ターン/毎試合使いたい ②複数枚あっても腐らない ③初動・サーチ・主力アタッカー・カウンター。 **サーチカードは4枚が最低ライン** (4枚35%↔3枚28%で「全然違う」)。
  - **同役割は種類をまたいで合計枚数で数える** (2種8枚で初手60%=毎試合1枚水準)。
- **サーチによる「実質枚数の水増し (圧縮)」**:
  - 中核判定式: **デッキ残枚数 ÷ 欲しいカード合計残枚数 ≦ サーチのめくり枚数(≒5) ならヒット期待** (例 44/11=4≤5でOK)。
  - サーチ成功率は「サーチ札の枚数 × 対象カードの厚み」の二段構え (対象14枚で初手82.2%、 20枚で93.3%)。
  - サーチで前倒しできる分 **フィニッシャー/コンボパーツ本体の採用枚数を減らせる** (前提 = 対象がデッキに十分ある)。
- **3枚/2枚/ピン刺しの基準 (両論)**:
  - 説1 (期待値重視): ピン刺しは初手10%しか引けず2枚までで十分。 1枚は「サーチで確実に持ってこられる/1枚で仕事が終わる切り札/複数枚だと腐る」に限定。
  - 説2 (柔軟性重視): 1枚採用は選択肢を広く保つ流動的アプローチ。
  - リーダーが継続サーチ・ドローを持つと母数が増え個々の採用枚数を抑えられる。

## 5. カードタイプ比率・ブロッカー・除去
- **種別配分の黄金比**: キャラ40〜50 / イベント0〜10 (約10前後) / ステージ0〜4。 **キャラ中心 (8〜10割)**。 ステージは場に1枚制約ゆえ多投しない。 ★★
- **ブロッカー枚数 (明確・アーキ別)** ★★: **アグロ ≈ 8枚 / コントロール ≈ 4枚**。 理由 = アグロは盤面を守って殴り勝つので防御札が要る / コントロールは除去とライフ操作で捌く。 1コストブロッカーは扱いやすく重宝。
- **除去 (KO/バウンス/レスト)**: 固定枚数目安は乏しく、 **色選択そのもので除去量を担保** (青黒=バウンス/KO中心)。 **ブロッカー約4枚⇔除去厚め / ブロッカー約8枚⇔除去薄い** の反比例で語られる。

## 6. 事故を減らす安定性設計 / マリガン
- **初動の必要枚数** ★★★: 3コスト帯は **合計6枚以上**で下ブレしにくい (4枚41%↔2種8枚67%)。 3T目の4〜5コストは **6枚で61.6%**。 「4枚だと安定しないので役割ごと+1〜2枚」。
- **サーチによる安定化**: サーチ手段を **2種8枚**で初手約60%。 一般採用量4〜8枚。 対象は14〜20枚厚く。
- **トリガー (黄・受け札) の枚数 (両論)**: 説1 (汎用)「狙うなら8枚≈60%」/ 説2 (確率突き詰め)「毎試合安定2枚発動なら最低17〜18枚」。 要求水準の違い。
- **マリガン設計** (手札5枚全戻し引き直し、 1試合1回、 先攻が先):
  - **「迷ったらキープ」** (迷う=欲しい札が1枚はある証拠、 最悪は"出す札が無い"事故)。
  - **カウンター値だけでキープするな** (最悪手=2000カウンターのみでメインアタッカー無し)。
  - **サーチがあるだけではキープ理由にならない** (欲しい札が明確なら3枚サーチよりマリガン5枚引き直しが当たる場面あり)。
  - **対面ごとに「見たい札2枚」を事前決定**し、 来たらキープ。 漠然と上振れ狙いのマリガンはしない。
- **上振れ vs 下振れ (設計思想)**: 説1 (安定重視) = 役割8枚単位で下ブレを潰し「6試合に1回しか事故らない構築」/ 説2 (上振れ重視) = 派手な動きの枠を残す。 多くのガイドは「初心者はまず上位構築を1枚も変えず丸パクリ→上振れ狙いは実力がついてから」。

## 7. メタ対応 (tech枠) / アーキタイプ別の構築思想
- **公式サイドボードが無い** → メタ枠は常時デッキに積みっぱなしで非該当対面では腐りうる (構造的トレードオフ)。 ★★
- **定量トレードオフ** (黒クロコ論): メタカードを4枚採用すると **その4枚分カウンター値が下がる** (tech枠4枚 ≈ カウンター値 -4000〜8000相当の代償)。 → **理想 = 「デッキ本来のパワーを削らずにメタる」** = 腐らない汎用性を兼ねるカードを優先。 **自由枠の多いデッキほどメタ対応しやすい**。
- メタカード実例: プリン (手札引き直し→サーチ依存対策)、 光月おでん (コスト6以下無効→システムキャラ封じ)、 ニコ・ロビン (耐久フィニッシャー兼受け)。

**アーキタイプ別の構築差**
| 軸 | アグロ (速攻) | ミッドレンジ | コントロール |
|---|---|---|---|
| 勝ち筋 | 盤面より早くライフを削り切る | 序盤捌き→中盤キーカード展開 | 防御→終盤に相手息切れで制圧、 リソース勝ち |
| 展開コスト帯 | 低コスト(1〜3)横展開 | 中コスト帯 | 高コスト大型 |
| カウンター量 | 少なめ | 中 | 多め |
| ブロッカー | 約8枚 | 中 | 約4枚 (除去で代替) |
| キャラ | 小型多め | 小→大の繋ぎ | 大型多め・高額 |
- **相性三角形**: アグロ < ミッドレンジ / ミッドレンジ < コントロール / コントロール < アグロ。 総合原則 = **「自分の得意なレンジを抜ける前に決着をつけるプランで戦う」**。

## 諸説対立まとめ
1. カウンター配分: 値重視(+2000優先) vs 枚数=回数重視。
2. カウンター枚数の定義: 全体カウント30〜35 vs 専業カウント14〜20 (数え方違い、 合計40000で一致)。
3. コントロールのカウンター量: 除去型は少なめ vs 耐久型は多め (下位分類次第)。
4. カーブ形: 教科書的2〜3コスト山型 vs 実デッキの双峰型 (アーキ依存)。
5. ピン刺し: 期待値的に不要(2枚まで) vs 柔軟性のため有効。
