# Claude 教師 収集ガイド (claude_play.py で良質な蒸留データを打つ)

> Claude(cloud agent / subagent)が `scripts/claude_play.py` でデッキを操縦し、蒸留用の
> (盤面特徴, 勝敗) データを収集する時の **piloting 規律**。目的は「Claude の *意図した* 良い
> プレイ」を記録すること — 操作ミスや効果誤認が入ると教師データが劣化し、蒸留 value の
> 天井が下がる(教師の質 = 生徒の天井)。2026-07-02 の縮図検証(紫エネル 3 局)で判明した
> 落とし穴を集約。

## 収集モード
- **全コマンド先頭に `ONEPIECE_DIVLOG=1`**(各 MAIN 決定の v6 38次元特徴を `pending_<slug>.jsonl`
  に記録 → game_over で勝敗ラベル付与し `distill_<slug>.jsonl` へ flush)。

## CLI 操作の鉄則(= 操作ミスを教師データに混ぜない)
1. **`move <idx>` を盲目連打するな。** 合法手リストは 1 手ごとに再構成され idx がズレる。
   **毎手 `show` で読み直してから** `move` せよ(render にも警告あり)。
2. **攻撃・DON 付与は idx シフトしない iid 版を優先**:
   - `attack <iid> <target_iid|leader> [--don N]`(アタック前に DON を N 個載せて攻撃)
   - `don <iid> <n>`(キャラ/リーダーに DON を n 個まとめて付与)
3. 任意効果を **発動しない**時は 空 `choice`(または対象を選ばない)で辞退。
4. ヘッダーの「ターンN phase=MAIN 先攻=私」表示は残ることがある。**自分の手番か相手の攻撃対応
   かは末尾の `[私の手番]`/`[防御]` で判断**せよ。

## カード効果の種類を正確に区別(= 効果誤認を防ぐ)
- **パワー−X は KO ではない**(パワー修正。パワー0以下でも場に残り、相手ターンに切れる)。
  「除去」したいなら **KO 効果**を使う。パワー debuff を守りにメインで撃つのは無価値。
- **同値パワーは攻撃側が通る**(攻撃力 ≥ 防御力でダメージ)。6000 の攻撃を 6000 で受けても
  **守れない**。守るには防御力を攻撃力より **大きく**する(+2000 等)。
- 効果を **KO / パワー修正 / レスト / バウンス(手札戻し) / ドン操作 / ドロー** に分類し、
  目的に合ったものを選ぶ。「とりあえず撃つ」で除去でない効果を除去扱いするな。

## 多段効果の target-pick を最後まで処理せよ
- 1 枚のカードが **複数の対象選択**を要求することがある(例: 神の裁き OP15-075 =
  「自キャラに +1000」→ **その後「相手パワー3000以下を KO」**)。
- **1 つ目の choice を解決したら、続く KO/除去の choice も必ず処理**せよ。有効な除去対象が
  いるのに 2 つ目の pick を skip すると、強い除去を無駄にする(= 縮図検証で神の裁きの KO を
  取り逃した実例。engine の KO 自体は正常で、pick を処理しきれなかったのが原因)。

## デッキ別 piloting(例: 紫エネル aggro / cardrush_1454)
- `decks/<slug>.analysis.json` を読んで戦略・キーカード・マリガン方針を把握。
- **リーダー効果がエンジン型なら毎ターン積極起動**(エネル: 第2T+ 起動でドン加速)。
- aggro: 序盤展開 → 相手リーダーを殴りライフを削る → 早期決着。**詰めのターンは攻撃頭数を
  確保する横展開**を怠らない(パンプ偏重で control のカウンター壁を割れない失敗に注意)。
- **DON 規律**(エネル 6-DON プール): pay_don イベント(OP15-075/077 等)を序盤に乱発して
  DON を戻しすぎるな。攻撃/展開に使える DON を枯らさない。効果は意味あるタイミング/対象で。

## 完遂 & 報告
- `*** ゲーム終了 ***` まで打ち切る(最大 ~50 ターン)。詰まったら `show` で立て直す。
- 収集後: `wc -l db/claude_play/distill_<slug>.jsonl` で記録行数、勝敗ラベル(勝=1/負=0)、
  操作ミス/効果誤認の有無を報告(= このガイドの継続改善に使う)。
