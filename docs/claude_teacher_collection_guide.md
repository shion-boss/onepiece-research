# Claude 教師 収集ガイド (claude_play.py で良質な蒸留データを打つ)

> Claude(cloud agent / subagent)が `scripts/claude_play.py` でデッキを操縦し、蒸留用の
> (盤面特徴, 勝敗) データを収集する時の **piloting 規律**。目的は「Claude の *意図した* 良い
> プレイ」を記録すること — 操作ミスや効果誤認が入ると教師データが劣化し、蒸留 value の
> 天井が下がる(教師の質 = 生徒の天井)。2026-07-02 の縮図検証(紫エネル 3 局)で判明した
> 落とし穴を集約。

## 収集モード
- **全コマンド先頭に `ONEPIECE_DIVLOG=1`**(各 MAIN 決定の v6 38次元特徴を `pending_<slug>.jsonl`
  に記録 → game_over で勝敗ラベル付与し `distill_<slug>.jsonl` へ flush)。

## ★手の質を分別マーク: `flag-mistake` / `flag-discovery`(= 情報を捨てず 重みづけ・レビュー)
> **マークは hard-exclude ではない**(ohtsuki)。ミスからの学び(ミス局面の (state, outcome) も
> 実 signal)や「ミスと思ったが実は有効だった新発見」も拾う。マークは **重みづけ・分別・
> 新発見レビュー**のためであり、情報を捨てるためではない。
- 教師(Claude / pros02)も人間同様ミスる。**ミスに気づいたら、続けて `flag-mistake <理由>`**。
  直近の MAIN 決定局面(pending の最後の記録)に `mistake: true` が付与される。
  - 例: `flag-mistake 対象選択を index/iid 取り違えた`
  - 例: `flag-mistake 6コスエネルをブロッカーと誤認して防御札を攻撃に使った`
  - 例: `flag-mistake 過剰攻撃で不用意にライフを晒した`
  - distiller の既定は **`--mistakes keep`(全部含める、ミス局面も部分利用)**。
    `--mistakes downweight`(sample_weight を下げて部分利用)/ `--mistakes exclude`(clean のみ、
    実験用)も選べる。除外/減量した件数は print される。
- **定石(brief)に無いが効果的だった手・意外な良手**に気づいたら `flag-discovery <理由>`。
  `discovery: true` が付与され、**絶対に除外されず** distiller の report に件数が出る
  (= 後で人間/私がレビューして brief に還元する)。
- 理由は任意(未指定でも動く)。**直近1件のみ**マークするので、その手を打った直後に打つ。
- マークしても対戦は続行できる(盤面は残る)。マークは pending に効き、game_over で勝敗ラベルと
  共に distill へ透過的にコピーされる。

## ★基礎操作術を適用して打つ (= 教師の質の本体、 2026-07-18 ohtsuki 方針)
> **`docs/optcg_fundamentals.md` を必ず読んでから打つ。** 教師データの価値は「人間として上手い
> 操作」= この基礎操作術を体現した手を記録すること。 特に配備 AI が苦手な **攻め側** を demonstrate。
- **DON 付与のタイミング**: 攻撃前に全キャラ均等付与するな (= 配備 AI の悪癖、 手の内バレ + 無駄)。
  DON は残して素パワーで攻撃し、 相手の守りを見てから通したい攻撃に回す。 付与は **具体的理由**
  (≤4000除去回避で4000→5000 / リーサル到達 / opp leader へ届かせる / ブロッカー突破) がある時だけ。
- **攻撃順は 低パワー → 高パワー** (非リーサル): 各攻撃が前以上の要求値を積み相手カウンターを枯らす。
  高パワー先行はライフ受けでドンが無駄。 フラット(均等)に殴らず強弱をつける。
- **要求値 = 付与ドン×1000 + 1000** を意識し 2000〜4000 を強いる。 相手が最強攻撃をライフ受け
  できない形を作る。
- **カウンター/防御は最小限**: 完全防御済に切らない / 効果を不要時に撃たない / 序盤は受けて終盤に温存 /
  ライフ受けは手札が増える。 (= 配備 AI は守り側は整備済 8e0d45d/8b43070、 攻め側を教師で埋める)
- **マリガン**: 迷ったらキープ / 対面別に欲しいカード2枚 / サーチ単体はマリガン / カウンター有無は基準にしない。
- 迷ったら **リーダーアタック** (ノーリスクで相手手札-1 or ライフ-1)。

## CLI 操作の鉄則(= 操作ミスを教師データに混ぜない)
1. **`move <idx>` を盲目連打するな。** 合法手リストは 1 手ごとに再構成され idx がズレる。
   **毎手 `show` で読み直してから** `move` せよ(render にも警告あり)。
2. **攻撃・DON 付与は idx シフトしない iid 版を優先**:
   - `attack <iid> <target_iid|leader> [--don N]`(アタック前に DON を N 個載せて攻撃)
   - `don <iid> <n>`(キャラ/リーダーに DON を n 個まとめて付与)
3. 任意効果を **発動しない**時は 空 `choice`(または対象を選ばない)で辞退。
4. ヘッダーの「ターンN phase=MAIN 先攻=私」表示は残ることがある。**自分の手番か相手の攻撃対応
   かは末尾の `[私の手番]`/`[防御]` で判断**せよ。

## カード効果の種類を正確に区別(= 効果誤認を防ぐ)
- **パワー−X は KO ではない**(パワー修正。パワー0以下でも場に残り、相手ターンに切れる)。
  「除去」したいなら **KO 効果**を使う。パワー debuff を守りにメインで撃つのは無価値。
- **同値パワーは攻撃側が通る**(攻撃力 ≥ 防御力でダメージ)。6000 の攻撃を 6000 で受けても
  **守れない**。守るには防御力を攻撃力より **大きく**する(+2000 等)。
- 効果を **KO / パワー修正 / レスト / バウンス(手札戻し) / ドン操作 / ドロー** に分類し、
  目的に合ったものを選ぶ。「とりあえず撃つ」で除去でない効果を除去扱いするな。

## 任意コスト(optional_cost_confirm)の confirm/decline を取り違えるな
- 「ドン‼-N を払って登場/効果」等の任意コストは choice で確認される。**`choice 1` = 支払い実行 /
  `choice 0` = 辞退**(効果ごとに見え方が違うので迷ったら)、**打った後に DON 数/盤面の増減で
  発火したか必ず確認**せよ。取り違えると無料展開/強力効果を取り逃す(control 局で 8 コスト
  ドフラの登場時展開を辞退扱いで逃した実例)。

## リーダー redirect / 相手ターン効果の DON 規律(control の生命線)
- リーダーの「相手アタック時」効果(ドフラの redirect 等)は **相手ターンに active(使用可能)
  DON を消費**する。**自ターン終了時に active DON を必要数残さないと、翌相手ターンに発動不能**。
- 低ライフ control では「攻撃/パンプで DON を全部レストにしない」= redirect/カウンター用の
  active DON を残すのが勝敗を分ける(control 局はこの DON 規律で life 1 を 2 ターン守り勝った)。
- 低ライフ時の防御判断: 「このターンあと **何回** 殴られ得るか(相手の残 DON + rush)」を
  **先に数えてから** カウンター/ブロッカーを切れ(数え違いで守り札が空振りした実例)。

## 多段効果の target-pick を最後まで処理せよ
- 1 枚のカードが **複数の対象選択**を要求することがある(例: 神の裁き OP15-075 =
  「自キャラに +1000」→ **その後「相手パワー3000以下を KO」**)。
- **1 つ目の choice を解決したら、続く KO/除去の choice も必ず処理**せよ。有効な除去対象が
  いるのに 2 つ目の pick を skip すると、強い除去を無駄にする(= 縮図検証で神の裁きの KO を
  取り逃した実例。engine の KO 自体は正常で、pick を処理しきれなかったのが原因)。

## デッキ別 piloting(例: 紫エネル aggro / cardrush_1454)
- `decks/<slug>.analysis.json` を読んで戦略・キーカード・マリガン方針を把握。
- **リーダー効果がエンジン型なら毎ターン積極起動**(エネル: 第2T+ 起動でドン加速)。
- aggro: 序盤展開 → 相手リーダーを殴りライフを削る → 早期決着。**詰めのターンは攻撃頭数を
  確保する横展開**を怠らない(パンプ偏重で control のカウンター壁を割れない失敗に注意)。
- **DON 規律**(エネル 6-DON プール): pay_don イベント(OP15-075/077 等)を序盤に乱発して
  DON を戻しすぎるな。攻撃/展開に使える DON を枯らさない。効果は意味あるタイミング/対象で。

## 完遂 & 報告
- `*** ゲーム終了 ***` まで打ち切る(最大 ~50 ターン)。詰まったら `show` で立て直す。
- 収集後: `wc -l db/claude_play/distill_<slug>.jsonl` で記録行数、勝敗ラベル(勝=1/負=0)、
  操作ミス/効果誤認の有無を報告(= このガイドの継続改善に使う)。
